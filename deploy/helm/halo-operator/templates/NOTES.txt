WARNING: leader election is disabled. Do not run more than one replica without

Note that this operator VERIFIES node configuration and reports drift. It never
mutates a host. Components whose observation source is not yet wired report
NotObserved rather than claiming compliance, so an Unknown condition means
"not checked", not "broken".
